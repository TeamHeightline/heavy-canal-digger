# Гусеничный каналокопатель

Тяжёлая машина для прокладки водяных каналов в Factorio. Походный режим поднимает рабочую головку; рабочий опускает её и превращает грунт возле колеса в настоящие клетки воды.

**Это 100% вайбкодинг через Codex (OpenAI): весь код мода создан с помощью ИИ под руководством автора. 3D-модели сгенерированы через Tripo AI.**

## Версия и требования

**0.5.3**, Factorio **2.0**, зависимость `base >= 2.0.0`. Мод устанавливается самостоятельно; Space Age и Cargo Ships не обязательны. Водяные каналы можно копать на Наувисе.

## Открытие и стоимость

Открывается технологией **«Железная дорога» (`railway`)**, одновременно с локомотивом. Стоимость рассчитана на тяжёлую специализированную технику этого этапа игры.

| Компонент | Количество |
|---|---:|
| Сталь (`steel-plate`) | 100 |
| Железные шестерни | 80 |
| Двигатели | 20 |
| Электросхемы | 40 |
| Железные плиты | 100 |

Изготовление — **30 секунд**, выход — одна машина. Багажник — **80 ячеек**, топливный отсек — **3 ячейки**; используется химическое топливо, например уголь.

## Управление

1. Заправьте машину и сядьте в неё. **W** — вперёд, **S** — торможение и задний ход, **A/D** — поворот.
2. Откройте окно машины и выберите **«Перемещение»** или **«Работа»**. По умолчанию включено перемещение.
3. Походная скорость — до **30 км/ч**, рабочая — до **3 км/ч**. В рабочем режиме поворот в **пять раз медленнее**.
4. Для непрерывной копки двигайтесь **задним ходом по суше**. При движении вперёд машина выкапывает воду перед собой и останавливается у нового берега.

**R** поворачивает превью установки и стоящую машину. При переключении режимов сохраняются груз, топливо, пассажиры и прочность.

## Копка и ограничения

- Номинальная ширина канала — **5,75 клетки**. Контур привязан к клеткам карты и зависит от направления прохода. Ширина задумана для прямого коридора судов Cargo Ships; для крутых поворотов нужны расширения.
- За каждую **новую** клетку воды в багажник поступает **одна земля**. Повторный проход по воде землю не выдаёт. **20 земли → 1 отсыпка**.
- Двигатель потребляет **600 кВт**; фактическая копка требует дополнительно **1,8 МВт**. Пустое топливо или полный багажник останавливают работу. Бетон обрабатывается медленнее обычной земли.
- Под строениями, деревьями, растениями, камнями и скалами копать нельзя. Эти препятствия машина сама не удаляет.
- Машина ездит только по суше и не пересекает даже собственный канал. Грунт под шасси не затапливается; опасные повороты у воды отклоняются, сохраняя возможность отъехать по суше.
- Версия 0.5.3 убирает декоративную траву и украшения с выкопанной воды. При обновлении также очищается вода в области **±32 клетки** вокруг существующих машин. Украшения на суше, настоящие деревья и камни сохраняются.

## Графика

Оба положения взяты из отдельных предоставленных USDZ-моделей. Спрайты отрендерены в Blender: **64 направления**, ортографическая камера 45°, постоянный масштаб, мягкое освещение и тени. В рабочем режиме колесо имеет **четыре фазы**, которые сменяются при движении машины; на месте колесо стоит. Превью установки и призраки используют настоящий спрайт.

## Установка и обновление

Скачайте `heavy-canal-digger_0.5.3.zip` из [Releases](https://github.com/TeamHeightline/heavy-canal-digger/releases), закройте Factorio и положите архив **без распаковки** в папку `mods` пользовательского профиля. В Windows это `%APPDATA%\Factorio\mods`. Включите мод в меню игры.

Для ручной упаковки файлы репозитория должны лежать в каталоге `heavy-canal-digger_0.5.3` внутри ZIP. Существующие сохранения и данные режима машин поддерживаются при обновлении. Большие исходники USDZ/Blender не включены; необходимые игре спрайты уже в архиве.
